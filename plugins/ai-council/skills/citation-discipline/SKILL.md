# Citation discipline

Every rule here was learned from a real failure.

## Before a citation leaves your hands
1. **Re-read the exact line now,** with grep or a Read call at the cited line. A summary of an earlier session is not a source.
2. **Quote verbatim,** including capitalisation and the leading word. If you shorten a quote, quote a contiguous fragment and do not re-capitalise it.
3. **Confirm the path exists** relative to the stated base. Check that line numbers point to the quoted text, and record the section heading line for ranges.
4. **Search the corpus for contrary notes** on the same claim (words like "not", "no connection", "corrected", "withdrawn", strike-through). A claim that the corpus itself rules out does not go in.
5. Never write "cited in X" unless you grepped X and found it.
6. **"I wrote it" is also a claim.** Before a summary, handoff or grade file says a record was added (ledger rows, a log line, a correction), grep the file for it. Ledger rows V-0307 to V-0310 were cited in five grade files but had never been written.

## For handoffs to other agents
- Every factual line carries a file and line reference. Unverified items are marked "verify".
- Run a double-check pass over the finished handoff (each path, line and quote) before giving it to the user. Do not wait to be asked.

## Negative findings
- Never write "X has no Y" about a source you did not open. A research report said the official MCP registry and the main awesome-list "returned no council entries" when neither had been fetched, only reached through one domain-limited search. Codex fetched both and found several.
- Scope every negative to what was actually done: "not found in one search limited to these two domains; neither page was fetched."
- When a correction arrives, check it against the saved copy, then add it visibly to the original report.

## Raw notation on public pages
- Internal encodings (Manuel de Codage `nHb`, database ids, "as recorded in the archive") stay in source notes. Public copy uses proper diacritics and no archive talk.
