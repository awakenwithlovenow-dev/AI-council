---
description: Open the council hub app
---
Open the council hub for this project: run `tools/council/chamber/launch.py` with the project's Python (on Windows, `pythonw` so no console window stays open). It starts the hub on http://127.0.0.1:8790 if it is not running and opens it as an app window in Edge or Chrome. If `tools/council/chamber/` does not exist, run `/council-build` first.
